# Генератор анатомії зубів

Цей інструментарій збирає опціональний профіль одонтограми `measured` із невеликого набору канонічних донорських SVG-файлів та явної специфікації стоматологічної анатомії. Він не змінює історичний профіль `classic`.

## Структура володіння та потік даних

```text
spec.py класи постійних/молочних зубів та прив'язка до FDI
        ↓
source/*.svg канонічна геометрія донорів (межа ручного редагування)
        ↓
build.py + roots.py + graft.py + gum.py + fillings.py + overlays.py
occlusal.py класо-специфічна генерація контуру/горбків/фісур
        ↓
src/assets/teeth-svgs/measured/*.svg (згенеровано; не редагувати вручну!)
        ↓
src/odontogram.ts мапінг AnatomyProfile/орієнтація/підміна молочних зубів
src/perioGraphic.ts CEJ, реставрація коренів та рендеринг фуркацій
        ↓
verify.py + check_roundtrip.py + тести Python/Vitest/рендеру
```

Шість SVG безпосередньо у `src/assets/teeth-svgs/` є класичними ресурсами рантайму, які підтримуються вручну. Шість SVG у `tools/toothgen/source/` є канонічними виміряними донорами. Файли у `src/assets/teeth-svgs/measured/` є відтворюваним результатом генератора — редагуйте специфікацію, донора або правила трансформації замість цих файлів.

Усі анатомічно залежні шляхи проходять через спільні карти координат. Це забезпечує вирівнювання шарів карієсу, пломб, коронок, пульпи/ендодонтії, пломбування коренів/штифтів, імплантатів, переломів, ясен, кістки та пародонтологічних ілюстрацій. Клінічні ID є контрактом API і залишаються незмінними.

## Мапінг молочних зубів

Молочні класи: `51`, `52`, `53`, `54`, `55`, `71`, `72`, `73`, `74` та `75`, дзеркально відображені на протилежний квадрант. Вони займають постійні позиції 11–15 та 31–35, але рендерер підставляє молочний SVG і відображає молочний номер FDI, зберігаючи ключ стану. Верхні молочні моляри мають три корені; нижні молочні моляри мають два.

## Збирання та верифікація

За наявності встановленого `uv`:

```bash
uv run tools/toothgen/build.py
uv run tools/toothgen/verify.py
uv run tools/toothgen/check_roundtrip.py
```

Скрипти не мають сторонніх залежностей Python і можуть запускатися через звичайний `python`, якщо `uv` недоступний:

```bash
python -m unittest tools.toothgen.test_overlay_geometry -v
```
