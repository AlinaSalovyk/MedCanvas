# Security Policy

## Supported versions

This is a standalone React and TypeScript web application.
Security updates and improvements are applied directly to the application repository.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report security issues privately to the project maintainers. Please include enough detail to reproduce the issue and describe the potential impact.

## Scope

This application runs entirely in the browser and stores data locally. The most relevant risks are in how imported JSON or FHIR data is parsed and rendered, so reports about input handling, SVG rendering and data export are especially useful.
